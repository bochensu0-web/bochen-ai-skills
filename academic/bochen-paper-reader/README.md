# bochen-paper-reader

面向中国 AI/计算机本科生与科研入门学生的英文论文精读、源码对齐、外文翻译与实验室组会汇报助手。

- **核心特点**：支持 5 分钟速筛、三遍深度精读与消融水分审视；建立论文公式到 GitHub 源码文件与行段的精确映射；内置组会 8 页高分汇报框架与毕设外文翻译机翻纠错表。
- **不适用**：写自己的课程报告（用 `bochen-academic-writer`）、本科毕设全周期推进（用 `bochen-cn-engineering-paper`）。

示例：`使用 $bochen-paper-reader，帮我拆解这篇论文的核心方法与消融实验到底靠哪一项涨点，并整理一份 12 分钟组会汇报 PPT 提纲和导师可能追问的 3 个问题。`
