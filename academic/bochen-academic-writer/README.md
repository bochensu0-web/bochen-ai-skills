# bochen-academic-writer

面向中国大学生的课程论文、专业课实验/上机报告、文献综述、读书报告与中英摘要写作及审阅助手。

- **核心特点**：优先在原稿上做最小有效修改并保留个人声音；内置理工科实验报告防“贴图流水账”结构、文献综述横向对比法与英文摘要 Chinglish 修正规则；严禁编造任何引用或实验数据。
- **不适用**：本科毕业设计（论文）全流程（用 `bochen-cn-engineering-paper`）、单篇英文论文精读（用 `bochen-paper-reader`）。

示例：`使用 $bochen-academic-writer，以 Reviewer 模式检查我的操作系统实验报告草稿，指出逻辑和数据分析缺口并做最小修改，不要编造实验数据。`
