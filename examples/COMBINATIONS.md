# 组合使用示例

## 日常课程学习

> 使用 `$bochen-answer-style` 和 `$bochen-learning-tutor`。我基础不牢，请讲清楚中心极限定理为什么成立，先给直觉，再给一个数字例子，最后让我自己判断一个新例子。

## 算法学习

> 使用 `$bochen-answer-style`、`$bochen-learning-tutor` 和 `$bochen-code-algorithm-tutor`。从暴力解法开始讲最长递增子序列，重点解释优化到二分的方法是怎么想到的，并给适合考试手写的 C++。

## AI 数学学习

> 使用 `$bochen-answer-style`、`$bochen-learning-tutor` 和 `$bochen-ai-math-tutor`。从二维向量开始讲注意力机制，连接公式、shape、数字例子和 PyTorch 实现。

## 算法考试

> 使用 `$bochen-answer-style`、`$bochen-code-algorithm-tutor` 和 `$bochen-exam-master`。根据这份往年卷归纳图论题型、步骤分和易错点，给我两小时冲刺计划与一题模拟题。

## 机器学习考试

> 使用 `$bochen-answer-style`、`$bochen-ai-math-tutor` 和 `$bochen-exam-master`。我明天考试，请按单位时间得分讲偏差—方差、正则化和交叉验证，列出可能的问法与判分点。

## 课程论文

> 使用 `$bochen-answer-style`、`$bochen-academic-writer` 和 `$bochen-research-verifier`。先核验我引用的模型性能数据，再以 Reviewer 模式检查论证，最后只修改有问题的段落。

## 工科本科毕业论文

> 使用 `$bochen-answer-style`、`$bochen-cn-engineering-paper` 和 `$bochen-research-verifier`。我是北京交通大学人工智能专业本科生，请先按当届学院要求建立论文契约，再检查选题可行性、文献证据和实验方案；不要编造任何结果或引用。

## 技术排障

> 使用 `$bochen-answer-style` 和 `$bochen-tech-guide`。根据截图告诉我 GitHub 仓库创建页面下一步点哪里，先只给当前一步和成功标志。
