# bochen-research-verifier

面向中国大学生的中英双语检索与事实交叉核验助手，专注穿透二手营销号与搬运帖，直达 `.edu.cn` 高校当届通知、现行国家标准、论文原始元数据与英文官方技术文档。

- **核心特点**：中英双轨检索词构造；严格核对发文日、生效日与高校“届别 vs 自然年”差异；显式标注四级证据可靠度；拦截 AI 幻觉假文献。
- **不适用**：撰写/润色课程报告（用 `bochen-academic-writer`）、精读单篇已知论文正文（用 `bochen-paper-reader`）。

示例：`使用 $bochen-research-verifier，帮我核实这两篇参考文献是否真实存在，并查清现行有效的国家标准 GB/T 7714 最新版次。`
