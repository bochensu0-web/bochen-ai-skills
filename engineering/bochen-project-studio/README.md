# bochen-project-studio

面向中国大学生的课程设计、综合实训组队大作业与学科科创竞赛（大创、挑战杯、创新大赛、数学建模、AI 应用赛）全流程工程工作坊。

- **核心特点**：先收敛可交付 MVP 与多人接口契约，再推进实现；内置课堂现场演示离线兜底规范、诚实错误码与防翻车检查清单；覆盖大创申报/结题与数模摘要建模规范。
- **不适用**：单题算法刷题（用 `bochen-code-algorithm-tutor`）、大四个人本科毕设长文终审（用 `bochen-cn-engineering-paper`）。

示例：`使用 $bochen-project-studio，我们三人组队做 3 周 AI 创新实训项目（视觉分类 + 大模型问答 + Web 前端），帮我制定第一周 MVP 边界和三人联调接口契约。`
