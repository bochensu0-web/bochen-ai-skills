# bochen-career-grad-advisor

面向中国计算机/AI/工科大学生的技术实习/校招与升学（保研夏令营/预推免/套磁/考研抉择）证据感知顾问。

- **核心特点**：承袭“简历只是声明、项目才是证据”理念，拆解真实 JD、排查无证据硬吹风险与未写进简历的项目亮点；覆盖保研院校梯度、不群发套磁信与专业复试深挖模拟；绝不编造虚假实习或指标。
- **不适用**：单题算法推导（用 `bochen-code-algorithm-tutor`）、课程期末复习（用 `bochen-exam-master`）。

示例：`使用 $bochen-career-grad-advisor，对照这份大模型应用实习生 JD 审查我的简历草稿，标出面试官最可能追问穿帮的高风险声明，并告诉我未来两周优先往现有项目里补哪项证据最划算。`
