# 中国计算机/AI 大学生技术实习、简历防追问与保研实战手册

处理日常/暑期实习准备、技术简历重构、模拟技术面及保研（夏令营/预推免/考研复试）任务时按需读取本文件。

## 1. 技术简历动词分级与项目经历“防拷打”重构法

### 技能栏诚实动词约定（国内面试官潜台词）
- **精通**：读过核心源码、清楚底层数据结构与边界坑、在复杂场景调优过（本科生慎用，除非真能扛住连续 5 层底层追问！）。
- **熟练使用 / 熟悉**：在至少 1–2 个完整项目中独立设计和排障过，能讲清核心机制、常见报错与选型权衡（**主力推荐档位**）。
- **了解 / 掌握基础**：上过相关课程或跑通过最小实验，知道适用场景与基本原理。

### 项目经历 bullet 改造公式（告别“使用了 XX 技术实现了 XX 功能”）
低质量写法：`使用 Python、FastAPI、ChromaDB 和千问 API 实现了智能问答与垃圾分类系统，提升了用户体验。`（全是工具罗列，面试官无从看出你的技术含金量）。

高含金量且经得起追问的写法（**场景约束 + 技术决策与取舍 + 客观可复现证据**）：
- **写清为什么这样设计**：“为保证弱网及无 API Key 环境下服务可用，将语义解析（LLM）与确定性业务规则解耦，设计在线 RAG 失败自动回退本地规则引擎的双模链路，并通过静态资源白名单阻断敏感配置泄露。”
- **只写自己能解释怎么测出来的真实数字**：如“在 720 张独立测试集上 Accuracy 达 `87.9%`（Macro-F1 `87.8%`），定位出污染纸品与可回收物混淆主因后引入 `<0.60` 低置信度拦截”或“将 Docker 镜像体积从 `823MB` 裁剪至 `252MB`（剥离前端依赖树至可选 extra）”。

## 2. 技术面试 / 保研复试“简历深挖（Resume Attack）”必考 6 连问

帮用户模拟面试时，针对其简历上的头号项目，重点追问以下 6 类问题（答不上来就说明简历与证据存在断层）：

1. **个人边界题**：“这个项目是几个人做的？架构图里哪一块代码是你一行行亲手写的？如果现在让你现场改其中一个边界条件，你改哪个文件的哪个函数？”
2. **技术选型对比题**：“为什么这里选了 SQLite / ResNet18 / 规则引擎，而不是 PostgreSQL / ViT / 全交给大模型？什么规模或条件下你现在的方案会失效？”
3. **指标溯源题**：“简历上写的准确率 `88%` 或召回率 `100%` 是在多少样本上测的？测试集和训练集怎么防数据泄漏的？最典型的 Bad Case 长什么样？”
4. **排障真实性题**：“做这个项目时卡你最久的一个真实 Bug 是什么？当时看到的现象是什么，怎么一步步定位到根因并验证修好的？”
5. **理论联动题**（保研复试高频）：“你项目里用了交叉熵损失 / AdamW / RAG 余弦相似度，请口述一下它的数学形式，如果样本极度不均衡或向量维度很高会出什么问题？”
6. **诚实兜底法则**：遇到真不会的盲区，教用户**“先基于已知原理给出合理推导边界 + 坦诚承认该具体实现细节未实测过”**，绝对禁止在考官面前不懂装懂瞎编名词！

## 3. 保研联系导师（套磁信）高回复率结构模板

- **邮件标题**：`【202X届预推免/夏令营自荐】本科学校-专业-姓名-排名X/Y（前Z%）`（让老师在收件箱一眼看到硬背景，不写“致敬爱的XX老师的一封信”！）。
- **正文三段式（总长 300 字左右，一屏读完）**：
  1. **硬背景速览（3–4 行）**：就读院校专业、前五/六学期排名与专业人数（如 `5/120，前 4.2%`）、CET-6 分数、核心编程/科研经历一句话概括。
  2. **具体契合点（核心诚意段）**：点出阅读过老师课题组近期某篇具体论文或研究方向（写出论文简称与年份），用 2–3 句话谈自己手头做过的某个项目/实验与该方向的具体连接点或思考（**严禁把老师名字换掉就能群发给全院所有老师的万能夸赞段，也严禁还没拿到外校优营前同时向同一课题组多位老师海投撞车！**）。
  3. **礼貌收尾与附件说明**：说明意向申请批次（夏令营/预推免直博或学硕/专硕），附件合并为单个命名规范的 PDF（`姓名_学校_个人简历及成绩单.pdf`），附上个人 GitHub 代表作仓库链接（确保仓库 README 整洁、CI 绿灯、无敏感文件！）。
