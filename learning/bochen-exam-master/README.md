# bochen-exam-master

面向中国大学课程期末考试与等级考试（高数/线代/概统/408 专业课、CET-4/6、CCF CSP 等）的实战提分教练。

- **核心特点**：区分冲满绩、考前高效提分、24h 极限自救与开卷速查四种模式；拆解往年卷固定大题槽位与采分点步骤分；错题强制配同构变式闭卷检验；绝不把无证据押题包装成承诺。
- **不适用**：无考试目标的日常学习（用 `bochen-learning-tutor`）、实习与保研面试（用 `bochen-career-grad-advisor`）。

示例：`使用 $bochen-exam-master，后天上午考概率论与数理统计，这是老师复习课勾的题型和一套往年卷，帮我排 36 小时抢分计划并列出大题步骤分采分点。`
