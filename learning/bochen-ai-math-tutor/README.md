# bochen-ai-math-tutor

面向中国 AI/计算机大学生的数学推导与模型机制导师：打通大一高数/线代/概统、《机器学习》（西瓜书）、《统计学习方法》与现代深度学习 / 大语言模型（PyTorch、Transformer、LoRA、RAG、RLHF）的公式、张量 `shape` 与可运行代码。

- **适用**：看懂模型公式、手算前向/反向小例子、追踪张量维度、理解损失函数与优化器机制。
- **不适用**：纯 C++ 算法竞赛题（用 `bochen-code-algorithm-tutor`）、单篇顶会英文论文全文精读（用 `bochen-paper-reader`）。

示例：`使用 $bochen-ai-math-tutor，从二维数字例子出发讲清楚为什么 Self-Attention 要除以根号 d_k，并对照写出带 shape 注释的 PyTorch 代码。`
