# bochen-learning-tutor

面向中国大学生的通用课程个性化学习导师：先补概念发明动机与直觉，再无缝对齐国内课堂教材记号（同济高数/线代、浙大概统、严蔚敏数据结构、408 核心课），配套最小手算例题与理解检查。

- **适用**：课前预习、课后没听懂补基、作业分步引导、易混概念正反例辨析。
- **不适用**：OJ 代码排错（用 `bochen-code-algorithm-tutor`）、AI/PyTorch 机制（用 `bochen-ai-math-tutor`）、考前冲刺押重点（用 `bochen-exam-master`）。

示例：`使用 $bochen-learning-tutor，我线代基础很差，同济教材一上来就讲伴随矩阵和秩，请先用二维几何直觉讲清楚矩阵的秩到底是什么，再对回教材公式带我手算一题。`
