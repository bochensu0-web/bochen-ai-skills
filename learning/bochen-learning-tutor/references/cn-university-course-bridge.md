# 中国高校主流理工与计算机课程衔接指南

处理国内本科基础课与计算机核心专业课的概念补基时按需读取本文件，重点解决国内教材“重公理化编排、轻直觉动机”与课堂记号差异问题。

---

## 1. 数学公共基础课痛点与破局切口

### 高等数学（同济版体系）
- **常见卡点**：一上来背 $\varepsilon-\delta$ 极限语言、中值定理辅助函数构造像“变魔术”、多元微分全微分/偏导连续/可微三角关系混乱、重积分/曲面积分坐标系与投影搞反。
- **讲解切口**：
  - 极限与连续先画动态逼近图，把 $\varepsilon$ 讲成“甲方要求的误差精度”，$\delta$ 讲成“你需要在自变量上控制多窄的范围才能交差”。
  - 中值定理构造辅助函数前，先做几何平移/旋转直觉（罗尔定理 = 把斜割线拉平）或微分方程还原法，让学生知道辅助函数是怎么推出来的而非天降神兵。
  - 多元微积分始终画“条件强弱单向/双向箭头图”，每个不可逆箭头配一个经典反例（如分段分式函数）。

### 线性代数（同济版体系）
- **常见卡点**：第一章直接从逆序数和 $n$ 阶行列式展开讲起，完全没有空间变换直觉；伴随矩阵 $A^*$、初等矩阵左行右列、矩阵的秩 $r(A)$、基础解系全靠硬背口诀。
- **讲解切口**：
  - 凡涉及矩阵乘法、行列式、秩、特征值，先用**二维平面上的网格拉伸/旋转/拍扁**建立几何直觉（行列式 = 面积缩放倍率；行列式为 0 = 空间被拍扁降维；秩 = 变换后还剩几个真正独立的维度）。
  - 讲完几何直觉后，**必须对齐回国内教材记号**：伴随矩阵记为 $A^*$（提醒注意英文教材中 $A^*$ 常指共轭转置，避免看英文资料混淆）、增广矩阵 $(A \mid b)$、行最简形化法与自由未知量取值规范。

### 概率论与数理统计（浙大版体系）
- **常见卡点**：古典概型排列组合数重算/漏算；条件概率 $P(A|B)$ 与交事件 $P(AB)$ 混淆；连续型二维随机变量卷积公式/变量变换忘记画积分区域边界（导致上下限全错）；数理统计里样本均值分布、卡方/t/F 分布构造与置信区间 vs 假设检验逻辑绕晕。
- **讲解切口**：
  - 条件概率一律先用“样本空间缩小（分母从全集变成事件 $B$ 的面积/人数）”讲清。
  - 二维连续分布求边缘密度或函数分布，强制先画二维阴影有效支撑域（哪里 $f(x,y) > 0$），标出穿线积分上下限再动笔算积分。
  - 假设检验用“疑罪从无”类比小概率反证法，明确原假设 $H_0$、检验统计量、拒绝域与第一/二类错误。

## 2. 计算机核心课（408 与编程基础）衔接要点

### 数据结构（严蔚敏 C/类C伪代码体系）
- **常见卡点**：教材使用 `&L` 引用参数混合 C 语法（纯 C 编译器直接报错，C++ 才能编过）、指针二次解引用画不明白、KMP 的 `next` 数组 `0`-indexed 与 `1`-indexed 两套教材版本打架！
- **讲解切口**：
  - 遇到 KMP `next` / `nextval`、树与森林转换、B 树阶数定义（$m$ 阶 B 树节点关键字上下界）、平衡二叉树旋转、AOE 网关键路径时，**第一步先确认用户学校课件采用的是哪套下标/定义约定**（如 `next[1]=0` 还是 `next[0]=-1`），严格沿用其课堂口径作答，防止作业/期末判错。
  - 链表与树操作强制先用 ASCII 箭头图画出修改指针前后的先后顺序（为什么先连新节点后继，再改前驱，防止断链丢失地址）。

### 计组 / 操作系统 / 计算机网络
- **计组**：补码加减与溢出判断、IEEE 754 浮点数阶码偏置值（127 vs 128）、Cache 直接映射/组相联地址拆分（标记 Tag + 组号 Index + 块内偏移 Offset 按字节编址还是按字编址）、五段流水线数据冒险转发与阻塞周期计算。
- **操作系统**：PV 信号量同步互斥（先找临界资源与前驱关系，再确定初值与成对顺序，检查死锁风险）、页表多级地址转换（算清页内偏移位数与页表项字节数）、页面置换算法手算表格。
- **计算机网络**：子网划分与 CIDR 聚合、TCP 三次握手/四次挥手序号 `seq/ack` 追踪、慢开始与拥塞避免 `cwnd`/`ssthresh` 拐点手算图。
