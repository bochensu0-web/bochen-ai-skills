# bochen-code-algorithm-tutor

面向中国计算机/AI 大学生的 C/C++、Python、数据结构与算法导师，全面覆盖 LeetCode、PTA（拼题A）、洛谷、牛客网、蓝桥杯、CCF CSP、机试与课堂手写算法题。

- **核心特点**：从数据范围与暴力瓶颈自然推导出优化思路；精准区分核心代码模式、ACM 标准流模式与纸面手写步骤分模式；Debug 做最小修改并给出最小反例。
- **不适用**：深度学习公式推导（用 `bochen-ai-math-tutor`）、多模块大作业开发（用 `bochen-project-studio`）。

示例：`使用 $bochen-code-algorithm-tutor，我的 PTA 链表反转题最后一个测试点段错误，帮我定位触发反例并做最小修改。`
